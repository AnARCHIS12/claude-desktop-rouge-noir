# Contribuer

- Commits conventionnels (`feat:`, `fix:`, `docs:`).
- Aucun CDN, aucune requête réseau, aucun émoji ; symboles libertaires uniquement (diagonale rouge et noir, A cerclé).
- Tester sur une version récente de Claude Desktop et décrire la plateforme dans la demande de fusion.
- Valider avant envoi : `node --check extension/theme.js` et `bash -n scripts/*.sh`.
